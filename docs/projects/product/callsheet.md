# 콜시트 Frontend 개발

## 배경

콜시트는 촬영 일정표를 온라인에서 작성하고 모바일로 확인하는 서비스입니다. 촬영 현장의 감독·매니저 등이 일정표를 PPT로 작성하고 인쇄해 공유하던 업무를 온라인으로 전환하기 위해 개발했습니다.

## 팀과 역할

Frontend 1명 · Backend 1명 · PM 1명 · 외주 디자이너 1명이 4주간 진행한 프로젝트로, Frontend 개발을 전담하고 기획부터 배포까지 참여했습니다.

## 구현

- **프로젝트·콜시트 관리:** 프로젝트와 콜시트를 생성·관리하는 화면을 구현했습니다.
- **촬영 일정 편집:** DnD 기반 일정 편집과 Debounce 기반 입력 자동 저장을 구현했습니다.
- **공유·모바일 조회:** 콜시트를 공유하고 모바일에서 확인할 수 있도록 구현했습니다.

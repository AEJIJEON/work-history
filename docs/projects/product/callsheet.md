# 콜시트 Frontend 개발

## 배경

콜시트는 **촬영 일정표를 온라인에서 간편하게 작성하고 모바일로 확인하는 서비스**입니다.

사내 신규 사업 아이템 검증을 위해 시작한 프로젝트로, 촬영 현장의 감독·매니저 등이 일정표를 PPT로 작성하고 인쇄해 공유하던 업무를 온라인으로 전환하는 것을 목표로 했습니다.

## 내용

### 팀과 역할

Frontend 1명 · Backend 1명 · PM 1명 · 외주 디자이너 1명이 **4주간 진행한 프로젝트**입니다.

**Frontend 개발을 전담하고, 기획부터 배포까지 참여했습니다.**

### 구현 기능

- 프로젝트 및 콜시트 관리
- DnD 기반 촬영 일정 편집
- 콜시트 공유 및 모바일 조회
- Debounce 기반 입력 자동 저장

## 결과

촬영 일정표를 **온라인에서 작성·편집하고 공유하며, 모바일로 확인할 수 있는 서비스**를 구현했습니다.

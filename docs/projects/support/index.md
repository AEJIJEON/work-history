# 써폿

렌탈·구매·구인 기능을 제공하는 서비스입니다.

## 담당 역할

사용자 웹에서는 Frontend를 중심으로, **Admin에서는 Frontend와 NestJS Backend를 함께 개발했습니다.**

## 기술 스택

- Frontend: `TypeScript` `React` `Next.js` `React Query` `Recoil` `Chakra UI`
- Backend·DB: `NestJS` `Prisma` `MySQL`

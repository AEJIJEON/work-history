# 상품 유사도 검색

## 배경

촬영 장비와 소품에는 외래어·영문 명칭이 많아, **사용자가 발음으로 기억한 이름과 실제 등록된 상품명 사이에 차이가 생길 수 있다고 보았습니다.** 정확한 명칭을 입력하지 않아도 상품을 찾을 수 있도록 유사도 검색을 구현했습니다.

## 내용

전체 상품 데이터가 클라이언트에 로드되어 있는 기존 구조를 활용해 **별도의 검색 서버 없이** 검색 기능을 구현했습니다.

- 정규식 기반 순차 문자 매칭
- Levenshtein Distance 기반 유사도 검색
- 한글 자모 단위 비교
- 실제 상품 데이터 기반 유사도 임계값 조정

## 결과

20명을 대상으로 상품 탐색부터 주문 완료까지 걸리는 시간을 측정했습니다. 검색 기능 도입 전후를 비교한 결과, **평균 주문 소요 시간이 약 20% 단축되었습니다.**

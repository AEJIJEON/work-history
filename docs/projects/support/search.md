# 상품 유사도 검색

## 배경

사용자가 촬영 장비와 소품의 외래어 상품명을 등록된 표기와 다르게 입력할 수 있다는 가설을 바탕으로 유사도 검색을 도입했습니다. 예를 들어 ‘헤이저’를 ‘헤이져’나 ‘해이저’로 입력해도 상품을 찾을 수 있도록 했습니다.

## 구현

전체 상품 데이터가 클라이언트에 로드되어 있는 기존 구조를 활용해 별도의 검색 서버 없이 구현했습니다.

- **정규식 기반 매칭:** 입력한 글자 사이에 다른 문자가 있더라도 글자 순서가 일치하는 상품명을 찾도록 구현했습니다.
- **자모 단위 편집 거리 기반 유사어 탐색:** 입력어와 상품명에서 추출한 단어를 한글 자모로 분해한 뒤, Levenshtein 거리를 계산해 가장 유사한 상품명 단어를 찾도록 구현했습니다.

## 결과

검색 기능 도입 전부터 수집하던 Mixpanel 이벤트를 활용해, 촬영 날짜 선택 버튼 클릭부터 주문 완료까지의 소요 시간을 비교했습니다. 촬영 날짜 선택은 상품 탐색 페이지로 진입하는 시점입니다.

20명을 대상으로 도입 전후 데이터를 비교한 결과, 평균 주문 소요 시간이 약 20% 감소했습니다.

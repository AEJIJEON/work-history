# 대용량 이미지 업로드 HTTP 413 해결

## 문제

Admin의 프로젝트 정산 내역·파일 관리 기능을 개발하던 중 큰 이미지 파일 업로드 시 **HTTP 413 오류**가 발생했습니다.

## 초기 가설

NestJS `FilesInterceptor`의 파일 크기 제한을 의심해 설정을 변경했지만 문제가 지속됐습니다.

## 조사

조사 범위를 요청 경로 전체로 확대했습니다.

```text
Client → Nginx → NestJS
```

그 결과 **Nginx Reverse Proxy의 요청 크기 제한**을 원인으로 확인했습니다.

## 검증과 해결

개발 서버에서 Nginx 설정을 직접 변경해 가설을 검증했습니다.

이후 `.platform`에 Nginx 설정을 추가하고 Elastic Beanstalk 배포 번들에 포함해 **재배포 이후에도 설정이 유지되도록 구성했습니다.**

## 결과

**대용량 이미지 업로드 413 오류를 해결했습니다.**

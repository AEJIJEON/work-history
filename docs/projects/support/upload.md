# 대용량 이미지 업로드 HTTP 413 해결

## 배경

Admin의 프로젝트 정산 내역·파일 관리 기능을 개발하던 중 큰 이미지 파일 업로드 시 HTTP 413 오류가 발생했습니다.

## 원인 조사

NestJS `FilesInterceptor`의 파일 크기 제한을 의심해 설정을 변경했지만 문제가 지속됐습니다. 조사 범위를 `Client → Nginx → NestJS` 요청 경로로 확대하고, Nginx의 `413 Request Entity Too Large` 오류를 확인했습니다.

개발용 Elastic Beanstalk의 EC2 인스턴스에 직접 접속해 Nginx 요청 크기 제한을 변경한 뒤, 오류가 발생했던 동일 파일이 정상 업로드되는 것을 확인해 원인을 검증했습니다.

## 배포 반영 및 결과

검증한 설정을 `.platform`에 추가하고 CD 배포 번들에 포함해 재배포 시에도 적용되도록 구성했습니다. 재배포 후에도 동일 파일이 정상 업로드되는 것을 확인했습니다.

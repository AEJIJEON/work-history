# 대용량 이미지 업로드 HTTP 413 해결

## 배경

Admin의 프로젝트 정산 내역·파일 관리 기능을 개발하던 중 큰 이미지 파일 업로드 시 **HTTP 413 오류**가 발생했습니다.

## 내용

### 원인 조사

NestJS `FilesInterceptor`의 파일 크기 제한을 의심해 설정을 변경했지만 문제가 지속됐습니다. 조사 범위를 `Client → Nginx → NestJS` 요청 경로 전체로 확대했고, **Nginx Reverse Proxy의 요청 크기 제한**을 원인으로 확인했습니다.

### 개발 환경 검증과 CD 반영

개발용 Elastic Beanstalk 환경에서 관리하는 **EC2 인스턴스에 직접 접속해 Nginx 요청 크기 제한 설정을 변경**하고, 대용량 이미지 업로드가 정상 처리되는지 테스트했습니다.

검증한 설정을 `.platform`에 추가하고 CD 배포 번들에 포함해 **재배포 후에도 유지되도록 구성**했습니다.

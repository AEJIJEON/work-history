# Next.js 서버 실행 환경 이전

## 배경

Lambda@Edge에서 운영하던 Next.js 서비스에서 콜드스타트에 따른 초기 접속 지연이 발생했습니다. 또한 애플리케이션 규모가 커지면서 요청 처리 시간이 실행 시간 제한을 초과해 503 오류가 반복됐습니다.

초기 접속 지연과 실행 시간 제한 문제를 해소하기 위해, 사내에서 운영 중이던 Elastic Beanstalk 구성을 활용해 Next.js 서버를 이전했습니다.

## 구현

사내 API 서버의 운영 구성을 참고해 별도의 Elastic Beanstalk 환경을 구성했습니다. Next.js 배포 패키징을 구성하고, 기존 GitHub Actions와 Blue/Green 배포 방식을 적용했습니다.

## 결과

Next.js 서버를 EC2에서 상시 실행하는 구조로 전환해 콜드스타트에 따른 초기 접속 지연을 해소했습니다. 이전 후 실행 시간 제한 초과로 발생하던 503 오류도 더 이상 관찰되지 않았습니다.

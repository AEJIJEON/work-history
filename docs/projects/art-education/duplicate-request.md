# 그림검사 재검사 중복 요청 방지

## 배경

그림검사는 최초 검사 이후 한 번의 재검사를 허용했으나, 일부 사용자에게서 재검사를 진행할 수 없다는 VOC가 반복됐습니다.

## 원인 분석

Backend 로그에서 검사 API가 수 ms 간격으로 중복 호출되면서 검사 수행 횟수가 2회로 집계되어 재검사 기회가 소진되는 현상을 확인했습니다.

Loading State와 버튼 Disabled 처리는 적용되어 있었지만, 상태 변경이 화면에 반영되기 전에 연속 클릭이 발생할 가능성을 의심했습니다. 사용자 액션 로그를 추가해 실제 연속 클릭으로 API가 중복 호출되는 것을 확인했습니다.

## 해결

마지막 클릭 시각을 `useRef`에 저장하고, 최초 요청은 즉시 실행하되 1초 이내의 후속 클릭을 차단하는 Leading-edge Throttle을 적용했습니다. 로그에서 확인한 중복 요청이 수 ms 간격으로 발생한다는 점을 기준으로 차단 시간을 설정했습니다.

## 결과

적용 후 일주일간 API 요청 로그를 모니터링한 결과, 중복 요청이 관찰되지 않았습니다.

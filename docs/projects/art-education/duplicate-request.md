# 그림검사 재검사 중복 요청 방지

## 문제

AI가 그림을 잘못 분석할 가능성을 고려해 **그림검사 결과를 한 번 재검사할 수 있는 정책**이 있었으나, 일부 사용자에게서 재검사가 수행되지 않는다는 VOC가 반복됐습니다.

## 조사

Backend 로그에서 재검사 API가 **수 ms 간격으로 두 번 호출**되는 것을 확인했습니다.

기존에 Loading State와 Disabled 처리가 적용되어 있었지만 **State가 반영되기 전에 연속 클릭이 발생했을 가능성을 의심**했습니다. 사용자 액션 로그를 추가해 실제로 연속 클릭이 발생했음을 확인했습니다.

## 해결

마지막 클릭 시각을 `useRef`에 저장하고 **1초 이내 후속 클릭을 즉시 차단하는 Leading-edge Throttle**을 적용해 중복 요청을 방지했습니다.

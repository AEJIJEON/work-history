# 그림검사 재검사 중복 요청 방지

## 배경

AI가 그림을 잘못 분석할 가능성을 고려해 **그림검사 결과를 한 번 재검사할 수 있는 정책**이 있었으나, 일부 사용자에게서 재검사가 수행되지 않는다는 VOC가 반복됐습니다.

## 내용

Backend 로그에서 재검사 API가 **수 ms 간격으로 두 번 호출**되는 것을 확인했습니다.

Loading State와 버튼 Disabled 처리가 적용되어 있었지만, 상태 변경이 화면에 반영되기 전 연속 클릭이 발생할 가능성을 의심했습니다. **이를 검증하기 위해 사용자 액션 로그를 추가했고, 실제 연속 클릭으로 재검사 API가 중복 호출되는 것을 확인했습니다.**

마지막 클릭 시각을 `useRef`에 저장하고, **1초 이내 후속 클릭을 즉시 차단하는 Leading-edge Throttle**을 적용했습니다.

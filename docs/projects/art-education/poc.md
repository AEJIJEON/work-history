# AI 스케치와 그림심리검사 PoC

## 배경

그림을 시작하기 어려운 사용자에게 스케치 도안을 제공하고, 기존 그림심리검사를 디지털로 수행할 수 있도록 AI 그림 서비스의 PoC를 개발했습니다.

## 구현

### AI 스케치

빈 화면에서 무엇을 그릴지 막막한 사용자가 도안을 바탕으로 그림을 시작할 수 있도록 Frontend 전체를 구현했습니다.

- 프롬프트로 생성한 이미지 또는 업로드한 이미지를 스케치 도안으로 변환하는 기능 연동
- AWS EC2와 Nginx를 활용한 정적 배포

### AI 그림심리검사

빗속의 사람검사·만다라 색칠검사 등 기존 그림심리검사를 디지털로 수행할 수 있도록 사용자·관리자·슈퍼관리자 Frontend를 구현했습니다.

- AWS EC2에서 Next.js·Node.js·PM2·Nginx 기반 배포

### 공통 연동

- iframe과 `window.postMessage` 기반 사내 Drawing Tool 연동

## 결과

개발한 PoC는 여러 교육 박람회와 서울시 사용성 평가에서 참가자가 직접 체험하는 형태로 제공됐으며, 이후 아트봉봉스쿨의 AI 기능으로 확장됐습니다.

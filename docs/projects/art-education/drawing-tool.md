# 레거시 Drawing Tool 신버전 전환

## 배경

PoC 개발 당시 이전 담당자로부터 안정화된 버전으로 전달받은 사내 Drawing Tool v1.0을 AI 서비스에 연동했습니다. 해당 버전은 **약 5개월간 시연·이벤트 환경에서 큰 문제 없이 사용**됐으며, 이러한 사용 이력을 바탕으로 실서비스에도 적용했습니다.

## 내용

### 문제 확인과 전환 결정

실서비스에서는 저장 이미지에 회색 배경이 포함되거나 비율이 왜곡되는 **간헐적인 문제가 발생했습니다.** 이미지 처리 흐름을 추적해 Drawing Tool이 반환한 Base64 자체에 문제가 있음을 확인했습니다.

기존 버전 담당자가 부재해 원인 파악과 수정에 어려움이 있었고, 현재 Drawing Tool 담당자의 도움으로 일부 문제를 해결했지만 모든 문제를 해소하지는 못했습니다. 담당 팀과 유지보수 가능성을 검토한 뒤, 개별 문제를 계속 수정하는 대신 최신 안정화 버전으로 통합하기로 결정했습니다.

### 연동 검증과 실서비스 전환

신버전에서는 그림 과정 데이터가 **JSON에서 Protobuf로 변경**되었습니다. AI 담당자가 변경된 데이터와 연동을 검증할 수 있도록, **Drawing Tool을 사용해 그림을 그리고 완성된 그림의 이미지와 그림 과정 데이터를 추출할 수 있는 테스트 페이지**를 구현했습니다.

**충분한 연동 테스트를 거친 후 실서비스의 Drawing Tool을 신버전으로 전환했습니다.**

## 회고

안정성은 버전 명칭이나 과거 사용 이력만으로 판단할 수 없으며, **실제 서비스 환경과 사용 사례를 기준으로 검증해야 한다는 점**을 배웠습니다. 시연·이벤트에서 문제가 없었더라도 실서비스 도입 전에는 관련 팀과 데이터 호환성, 유지보수 가능성을 충분히 검토해야 했습니다.

또한 서비스 연동 담당자와 솔루션 개발 담당자의 역할 및 유지보수·지원 범위를 사전에 명확히 합의하는 것이 중요하다는 점을 배웠습니다. 이 경험을 통해 사내 솔루션뿐 아니라 외부 솔루션·써드파티 라이브러리·외부 API를 도입할 때도 **기능 연동과 함께 안정성 검증 및 문제 발생 시 대응 방안을 검토해야 한다는 점을 배웠습니다.**

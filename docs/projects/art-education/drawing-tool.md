# 레거시 Drawing Tool 신버전 전환

## 문제

그림검사 서비스에서 **최종 저장되는 그림 이미지에 회색 배경이 포함되거나 비율이 왜곡되는 문제**가 간헐적으로 발생했습니다.

## 조사와 전환 결정

이미지 처리 흐름을 추적해 **Drawing Tool에서 반환되는 Base64 자체가 이미 비정상적**임을 확인했습니다.

기존 버전의 유지보수가 어려운 상황임을 Drawing Tool 담당 부서를 통해 확인했습니다. 문제 상황을 공유한 뒤 팀장·부서장과 논의해 기존 버전을 수정하는 대신 **신버전 Drawing Tool로 전환**했습니다.

## 연동 검증

신버전에서는 그림 과정 데이터가 **JSON에서 Protobuf로 변경**되었습니다.

AI 담당자가 변경된 그림 과정 데이터를 확인하고 연동을 검증할 수 있도록 테스트 페이지를 구현했습니다.

- 신버전 Drawing Tool 그림 생성
- Protobuf 과정 데이터 다운로드
- 결과 이미지 다운로드

## 결과

학생 서비스의 Drawing Tool을 신버전으로 전환했으며, **기존에 발생하던 이미지 저장 관련 VOC가 다시 발생하지 않았습니다.**

# 레거시 Drawing Tool 신버전 전환

## 배경

사내에서 개발한 Drawing Tool v1을 인수받아 AI 서비스에 연동했고, 약 1년간 시연·이벤트에서 사용했습니다. 그러나 실서비스 적용 후 **저장 이미지에 회색 배경이 포함되거나 비율이 왜곡되는 문제**가 간헐적으로 발생했습니다.

Drawing Tool 개발팀의 v2는 다른 실서비스에서 사용 중이었지만, AI 분석에는 v1에서 수집한 그림 과정 데이터가 사용되고 있어 버전 전환 시 데이터 호환성 검토와 연동 작업이 필요했습니다.

## 내용

### 원인 추적과 전환 결정

이미지 처리 흐름을 추적해 **Drawing Tool에서 반환되는 Base64 자체가 이미 비정상적**임을 확인했습니다.

담당 팀과 기존 버전의 유지보수 가능성을 확인하고 문제 상황을 공유했습니다. 팀장·부서장과 논의해 기존 버전을 수정하는 대신 **신버전 Drawing Tool로 전환**하기로 결정했습니다.

### AI 데이터 호환성 검증

신버전에서는 그림 과정 데이터가 **JSON에서 Protobuf로 변경**되었습니다. AI 담당자가 변경된 데이터를 확인하고 연동을 검증할 수 있도록 다음 기능을 갖춘 테스트 페이지를 구현했습니다.

- 신버전 Drawing Tool 그림 생성
- Protobuf 과정 데이터 다운로드
- 결과 이미지 다운로드

## 결과

학생 서비스의 Drawing Tool을 신버전으로 전환했으며, **기존 이미지 저장 관련 VOC가 다시 발생하지 않았습니다.**

### 회고

시연·이벤트 환경에서의 사용 이력만으로 실서비스 안정성을 판단하기는 어렵다는 점을 경험했습니다. 공통 솔루션을 도입할 때는 실제 사용 사례와 데이터 호환성을 관련 팀과 함께 검증해야 합니다.

또한 서비스 연동 범위와 솔루션 자체의 유지보수 범위를 구분하고, 담당 팀과 지원 범위를 사전에 확인하는 것이 중요하다는 점을 배웠습니다.

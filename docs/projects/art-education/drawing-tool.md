# 레거시 Drawing Tool 신버전 전환

## 배경

PoC 개발 당시 이전 담당자로부터 안정화된 버전으로 전달받은 사내 Drawing Tool v1.0을 AI 서비스에 연동했습니다. 해당 버전은 약 5개월간 시연·이벤트 환경에서 큰 문제 없이 사용됐으며, 이러한 사용 이력을 바탕으로 B2C 실서비스에도 적용했습니다.

## 내용

### 실서비스 이미지 오류 분석

B2C 서비스 운영 과정에서 Drawing Tool에서 추출된 이미지에 회색 배경이 포함되거나 비율이 왜곡되는 간헐적인 문제가 발생했습니다.

서비스의 이미지 처리 흐름을 추적해 프론트엔드의 이미지 가공 과정이 아닌 Drawing Tool에서 반환되는 Base64 데이터 자체에 문제가 있음을 확인했습니다.

해당 Drawing Tool 버전의 담당자가 부재해 원인 파악과 수정에 어려움이 있었고, Drawing Tool을 개발하는 타 부서에 발생 현상과 확인한 내용을 공유해 문제를 함께 확인했습니다. 담당자의 도움으로 일부 문제를 해결했지만, 현재 버전에서 모든 문제를 해결하기에는 투입할 수 있는 리소스가 제한적이었습니다.

타 부서와 논의하는 과정에서 최신 안정화 버전으로의 업그레이드가 필요하다는 점을 확인했고, 이를 소속 부서에 공유해 기존 AI 모듈의 마이그레이션 가능 여부와 필요한 공수를 검토했습니다.

### 신버전 마이그레이션 검증 환경 구현

신버전에서는 기존 AI 모듈에서 활용하던 그림 과정 데이터의 형식이 JSON에서 Protobuf로 변경되어 연동 가능 여부에 대한 사전 검증이 필요했습니다.

담당자들이 신버전의 동작과 변경된 데이터를 직접 확인할 수 있도록 Drawing Tool에서 그림을 그리고, 완성 이미지와 그림 과정 데이터를 추출할 수 있는 테스트 페이지를 구현해 제공했습니다.

이를 통해 기존 AI 모듈 담당자들이 실제 데이터를 기반으로 신버전과의 연동 가능 여부와 마이그레이션에 필요한 공수를 검토할 수 있도록 지원했습니다.

이후 충분한 연동 테스트를 거쳐 B2C 실서비스의 Drawing Tool을 신버전으로 전환했습니다.

## 회고

시연과 이벤트 환경에서 약 5개월간 문제없이 사용한 버전이었지만, B2C 실서비스의 다양한 환경에서는 예상하지 못한 문제가 발생했습니다. 이를 통해 PoC나 기존 사용 이력만으로 기술의 안정성을 판단해서는 안 된다는 점을 배웠습니다.

특히 사내 솔루션이나 외부 기술을 서비스에 적용할 때는 기능 구현 여부뿐만 아니라 실제 운영 환경에서의 안정성, 데이터 호환성, 향후 유지보수 가능성까지 함께 고려해야 한다는 점을 경험했습니다.

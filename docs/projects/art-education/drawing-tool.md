# Drawing Tool 마이그레이션 및 AI 연동 검증 지원

## 배경

B2G 디지털 미술 교육 서비스 운영 중 일부 사용자 환경에서 Drawing Tool의 추출 이미지에 회색 배경이 포함되거나 비율이 왜곡되는 문제가 발생했습니다.

Drawing Tool 개발 부서에 발생 현상과 확인한 내용을 공유하는 과정에서 레거시 버전의 담당자가 부재한 상황임을 알게 됐습니다. 일부 오류는 해결했지만 유지보수에 제약이 있어, 타 부서와 협의해 신버전 전환을 추진했습니다.

## 구현 및 검증

신버전에서는 그림 과정 데이터의 구조가 변경되고 직렬화 형식도 JSON에서 Protobuf로 전환되어, 기존 AI 모듈과의 연동을 사전에 검증해야 했습니다.

신버전 Drawing Tool에서 직접 그림을 그리고 완성 이미지와 그림 과정 데이터를 추출할 수 있는 테스트 페이지를 구현했습니다. AI 모듈 개발자들은 추출 데이터를 기존 AI 모듈의 입력 형식으로 변환하는 Converter가 정상 동작하는지 검증했습니다.

## 결과

연동 검증을 거쳐 B2G 실서비스의 Drawing Tool을 신버전으로 마이그레이션했습니다. 이후 지속적으로 모니터링한 결과, 기존과 동일한 이미지 오류는 관찰되지 않았습니다.

# AI 민원 시스템

AI를 활용해 접수된 민원의 담당자 배정을 지원하고, 유사 민원 사례·관련 법령·답변 초안 생성 기능을 제공하는 공공 AI 민원처리 시스템입니다.

## 담당 역할

Frontend 파트를 담당하며 프로젝트를 시작했으나, **Backend 인력 공백을 계기로 FastAPI와 DB까지 담당 범위를 확장**했습니다. 이후 SSO 연동, 폐쇄망 환경 운영 및 장애 대응까지 담당했습니다.

`Next.js` `TypeScript` `FastAPI` `Python` `PostgreSQL` `Nginx`

# 민원 처리 Workflow Backend 설계 및 구현

## 배경

Backend 인력 공백 동안 민원 처리에 필요한 API와 DB 구조를 구현해야 했습니다.

## 내용

기존 FastAPI Router와 Scheduler 기반 AI 처리 Pipeline을 분석해 데이터 흐름을 파악하고 다음 기능을 구현했습니다.

- 담당자 배정·재배정 API
- 민원 반려·완료 처리 API
- 민원 처리 상태·배정 상태 조회 API
- 관련 DB 구조 설계

**AI 분석 진행 상태와 민원 처리·배정 상태를 분리**하고, AI 분석이 완료된 민원만 서비스 화면에 노출되도록 구현했습니다.

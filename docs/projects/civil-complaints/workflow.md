# 민원 Workflow Backend 설계 및 구현

## 데이터 흐름 파악

기존 FastAPI Router와 Scheduler 기반 AI 처리 Pipeline을 분석해 데이터 흐름을 파악하고, **서비스에 필요한 Backend API와 관련 DB 구조를 구현했습니다.**

## 구현 범위

- 담당자 배정·재배정 API
- 민원 반려·완료 처리 API
- 민원 처리 상태·배정 상태 조회 API
- 관련 DB 구조 설계

## 상태 분리

**AI 분석 진행 상태와 공무원의 민원 처리·배정 상태가 독립적으로 변경되는 구조를 고려해 상태를 분리**했습니다. AI 분석이 완료된 민원만 서비스 화면에 노출되도록 구현했습니다.

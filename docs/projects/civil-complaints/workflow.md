# 민원 처리 Workflow Backend 설계 및 구현

## 배경

Backend 인력 공백 동안 민원 처리에 필요한 API와 DB 구조를 구현했습니다. 기존에는 AI 분석 상태만 관리하고 있어, 배정 담당자와 민원 담당자의 배정·반려·완료 업무를 지원하는 상태와 처리 로직이 필요했습니다.

## 구현

기존 FastAPI Router와 Scheduler 기반 AI 처리 Pipeline을 분석하고, AI 분석 상태와 독립적으로 민원 업무 상태를 관리하도록 DB 구조와 API를 설계했습니다.

- **담당자 배정·재배정:** 배정 담당자가 민원 담당자를 지정하거나 변경할 수 있도록 구현했습니다.
- **민원 반려·완료 처리:** 민원 담당자가 배정된 민원을 완료하거나 반려할 수 있도록 하고, 반려 시 배정 대기로 전환했습니다.
- **AI 분석 결과 연동:** AI 분석이 완료된 민원만 서비스 화면에 노출하도록 구현했습니다.

## 검증 결과

화면 연동 테스트를 통해 배정 담당자의 배정 후 민원 담당자의 완료 처리와, 반려 후 재배정 흐름이 정상 동작하는 것을 확인했습니다.

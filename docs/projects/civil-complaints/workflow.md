# 민원 처리 Workflow Backend 설계 및 구현

## 배경

Backend 인력 공백 동안 민원 처리에 필요한 API와 DB 구조를 구현해야 했습니다.

## 내용

기존 FastAPI Router와 Scheduler 기반 AI 처리 Pipeline을 분석해 데이터 흐름을 파악하고 다음 기능을 구현했습니다.

- 담당자 배정·재배정 API
- 민원 반려·완료 처리 API
- 민원 처리 상태·배정 상태 조회 API
- 관련 DB 구조 설계

민원 처리·배정 상태는 사용자가 화면에서 수행하는 담당자 배정·재배정, 반려·완료 등의 업무 흐름에 따라 변경되며, AI 분석 진행 상태와 독립적으로 관리되어야 했습니다. 이에 AI 분석 상태와 민원 처리·배정 상태를 분리해 설계하고, 각 상태를 조회·변경하는 API를 구현했습니다.

AI 분석이 완료된 민원만 서비스 화면에 노출하고, 이후 사용자의 업무 처리에 따라 민원 처리·배정 상태가 변경되도록 구현했습니다.

# 공공기관 SSO 연동

## 배경

새올 시스템에서 인증된 공무원이 별도 로그인 없이 AI 민원 시스템에 진입할 수 있도록 인증 연동이 필요했습니다.

해당 SSO는 Tomcat 환경에 인증 모듈을 설치하고, 인증 후 세션에 저장된 사용자 정보를 조회하는 방식으로 연동하는 구조였습니다.

## 인증 연동 구성

![SSO 일회용 인증 코드 연동 시퀀스](/diagrams/sso-sequence.svg)

## 구현

- **SSO 사용자 조회 및 인증 코드 발급:** 인증 후 세션에 저장된 사용자 정보를 조회하는 Java Servlet을 구성하고, 조회한 정보로 FastAPI에 짧은 TTL의 일회용 인증 코드 발급을 요청했습니다.
- **서비스 인증 연결:** 일회용 인증 코드를 URL 파라미터로 Next.js Route Handler에 전달했습니다. Route Handler에서 FastAPI에 코드를 전달해 서비스용 JWT로 교환하고, JWT를 쿠키에 저장한 뒤 서비스 루트 경로로 리다이렉트하도록 구현했습니다.
- **요청별 인증 검증 및 실패 처리:** Next.js Proxy에서 서비스 요청마다 인증 정보의 유효성을 검증하고, 토큰 만료 또는 인증 실패 시 오류 페이지로 리다이렉트하도록 처리했습니다.

## 검증 결과

새올 시스템에 로그인한 사용자가 별도 로그인 없이 AI 민원 시스템에 진입하는 것을 확인했습니다.

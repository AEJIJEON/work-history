# 폐쇄망 구축 전 데이터 흐름 검증

## 배경

실제 국민신문고 민원 데이터 연동은 폐쇄망 현장에서 최종 검증해야 했으며, 민원은 매일 한 번 수신되는 구조였습니다. 현장 구축 전에 유사 민원 검색과 AI 처리 흐름을 테스트할 환경이 필요했습니다.

## 구현

- **유사 민원 검색용 과거 데이터 구축:** 기존 적재 스크립트를 활용해 약 10년치 과거 민원 데이터를 테스트 서버에 적재하고, 유사 민원 검색을 테스트할 수 있는 환경을 구축했습니다.
- **신규 민원 반복 테스트 지원:** 테스트 민원 파일을 업로드해 기존 AI 처리 흐름으로 실행할 수 있는 엔드포인트를 구현했습니다. 실제 민원 수신을 기다리지 않고 반복적으로 테스트할 수 있도록 했습니다.

과거 민원 데이터를 활용한 유사 민원 검색과, 테스트 민원 적재부터 AI 처리 결과의 화면 노출까지 반복적으로 검증할 수 있었습니다.

# 폐쇄망 구축 전 데이터 흐름 검증

## 배경

실제 국민신문고 민원 데이터 연동은 **폐쇄망 현장에서만 최종 검증할 수 있으며, 민원이 매일 한 번 수신되는 구조**였습니다. 실제 민원 수신을 기다리지 않고 각 기능과 전체 처리 흐름을 검증할 방법이 필요했습니다.

처음에는 일회성 스크립트로 데이터를 적재했으나, 검색 결과와 AI 처리 과정, 화면에 반환되는 결과를 테스트할 때마다 여러 담당자로부터 적재 요청이 발생했습니다. 저 역시 개발한 기능을 검증하기 위해 반복적으로 데이터를 넣어야 했습니다.

## 내용

기존 Backend 개발자가 작성한 적재 스크립트를 전달받아 **약 10년치 민원 데이터를 테스트 환경에 적재**했습니다.

현장 구축이 가까워질수록 테스트가 더 빈번해질 것으로 판단했습니다. 반복 요청에 매번 스크립트로 대응하는 대신, **필요할 때 테스트 데이터를 직접 적재하고 기존 Scheduler 처리 로직으로 전달할 수 있는 엔드포인트**를 구현했습니다.

</ol>

## 결과

**군청에 시스템을 구축하기 전까지 필요한 테스트 데이터를 활용해 전체 시스템 흐름을 반복적으로 검증할 수 있었습니다.**

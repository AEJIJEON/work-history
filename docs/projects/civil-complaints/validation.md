# 폐쇄망 구축 전 데이터 흐름 검증

## 배경

실제 **국민신문고 민원 데이터 연동은 폐쇄망 현장에서만 최종 검증**할 수 있었기 때문에, 구축 전에 전체 처리 흐름을 반복적으로 확인할 방법이 필요했습니다.

## 구현

기존 Backend 개발자가 작성한 민원 데이터 적재 스크립트를 전달받아 **약 10년치 민원 데이터를 테스트 환경에 적재**했습니다. 테스트 민원을 기존 Scheduler 처리 로직으로 전달할 수 있는 엔드포인트를 구현했습니다.

```text
민원 유입 → AI 처리 → Frontend 노출
```

## 결과

실제 민원 유입을 기다리지 않고 전체 흐름을 사전에 검증할 수 있도록 했습니다.

# Index 및 Chunk 조회 기능

## 배경

채팅 검색 과정에서 LLM에 컨텍스트로 전달되는 벡터 검색 청크 데이터를 서비스 화면에서 확인할 수 있는 기능이 필요했습니다.

## 내용

기존 Qdrant 기반 데이터 저장 구조를 분석하고, 청크 목록과 상세 데이터를 조회하는 Frontend와 Backend API를 구현했습니다.

- File / DB 기반 청크 목록 조회
- 청크 상세 데이터 조회
- Vision 데이터 조회

## 결과

AI 응답 생성에 활용되는 검색 데이터의 청크 목록을 조회하고, 청크 단위로 내용을 확인·추적할 수 있는 구조를 만들었습니다.

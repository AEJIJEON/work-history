# Index 및 Chunk 조회 기능

## 배경

사용자가 자신의 데이터가 어떻게 청킹·인덱싱되고 채팅에 활용되는지 확인할 수 있도록 조회 기능을 구현했습니다. 기존 서비스 화면에서는 인덱싱 결과와 채팅 응답 생성에 활용된 청크를 확인할 수 없었습니다.

## 구현

기존 Qdrant 기반 데이터 저장 구조를 분석하고, 조회에 필요한 Frontend와 Backend API를 구현했습니다.

- **Index 조회:** Index 목록과 상세 정보를 조회할 수 있도록 구현했습니다.
- **채팅 활용 청크 추적:** 도구 실행 패널의 벡터 검색 탭에서 실제 LLM에 전달된 청크 목록을 확인하고, 선택한 청크의 상세 페이지에서 본문과 관련 메타데이터를 조회하도록 구현했습니다.
- **Vision 데이터 조회:** 원본 이미지와 AI가 생성한 이미지 설명 텍스트, 관련 메타데이터를 조회하도록 구현했습니다.

## 결과

사용자가 검색과 채팅 응답 생성에 활용되는 데이터를 직접 확인할 수 있게 해, 자신의 데이터가 AI 응답에 어떻게 활용되는지 파악할 수 있도록 했습니다.
